# Control Glossary

- **Agent**: Pydantic AI control brain using configured model and MCP tools.
- **Pupality**: Configured agent persona.
- **Tool descriptor**: File describing one MCP endpoint.
- **Skill**: Markdown guidance injected when dependencies available.
- **SOUL**: Persona identity/behavior document.
- **STT**: Browser speech-to-text coordinated by Ably.
- **TTS**: Text-to-speech service.
- **Caddy**: Reverse proxy for web and MCP endpoints.
